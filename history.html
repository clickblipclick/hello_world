hello world

Somebody had to say it first. This is how two words became the first thing a program is asked to say. This list only grows too. Back to the first page.

  • 1972
    Brian Kernighan writes a tutorial for the language B at Bell Labs. One of its examples prints the words.
    main( ) {
  extrn a, b, c;
  putchar(a); putchar(b); putchar(c); putchar('!*n');
}

a 'hell';
b 'o, w';
c 'orld';
    A constant in B held four characters at most, so the greeting came in three pieces.
  • 1974
    B becomes C, and Kernighan writes another tutorial. Now the words fit on one line.
    main( ) {
        printf("hello, world");
}
    Lower case, with a comma. That is how it was first spelled.
  • 1978
    Kernighan and Dennis Ritchie publish The C Programming Language. It is the first example in the book.“The first program to write is the same for all languages: Print the words hello, world.” After this, it was.
  • 2011
    Asked where the words came from, Kernighan says he is not sure, but remembers a cartoon of a chick coming out of an egg and saying them.Which is about right for a first program.
  • 2026
    A page is made that says only hello world, without the comma, and something is added to it every hour.You are reading part of it.
